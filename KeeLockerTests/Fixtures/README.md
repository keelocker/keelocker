# Synthetic fixtures

All credentials are artificial. Master password: `fixture-password`.

- `interop.kdbx`: KeePassXC 2.7.12 import of `interop.xml` with
  `keepassxc-cli import -p -t 100`; KDBX 3.1, AES-KDF/AES-256. Covers nested/empty
  groups, Unicode, protected fields, tags, TOTP and fixed timestamps.
- `filename-fallback.kdbx`: same import with whitespace-only DatabaseName.
- `review-attachments.kdbx`: KeePassXC import of `review-attachments.xml` with
  `-p -t 100`. Covers two binaries, names and entries sharing a binary, and
  an older attachment referenced only by history.
- `Matrix/xc-4{0,1}-{argon2d,argon2id}-{aes,chacha20}[-key].kdbx`: generated by
  the Rust integration test, rewritten by KeePassXC with a KeePassXC-created
  entry. Tests assert the actual resulting KDBX version.
- `Matrix/test.key`: public 32-byte key for `-key` fixtures.

To regenerate Matrix, set `KEELOCKER_MATRIX_OUTPUT=/absolute/path/to/KeeLockerTests/Fixtures/Matrix`
when running `cargo test -p keelocker-core keepassxc_crypto_matrix_roundtrip -- --ignored`.
No fixture comes from the removed Swift KDBX dependency.
